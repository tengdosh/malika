# Placeholder assets

Everything here is generated by `node scripts/gen-placeholders.mjs` and is meant
to be replaced with real photographs. The dimensions are the ones the real files
must have — swap the file, keep the name, and nothing else needs to change.

| File | Size | Ratio | Replace with |
|---|---|---|---|
| `portrait-placeholder.jpg` | 900×1200 | 3/4 | Malika's portrait (hero + `/men-haqimda`) |
| `covers/navbatchilikdan-keyin.jpg` | 1600×1200 | 4/3 | cover photo for that post |
| `covers/koz-oldidagi-chivinlar.jpg` | 1600×1200 | 4/3 | cover photo for that post |
| `covers/koz-anatomiyasi.jpg` | 1600×1200 | 4/3 | cover photo for that note |
| `books/hozir-oqiyapman.jpg` | 800×1200 | 2/3 | the current book's cover |

Covers are 4/3; CSS crops them to 1/1 for list thumbnails and 16/9 for the
article hero, so one file per post is enough.

Two more placeholders live outside this folder:

- **Signature** — `src/components/Signature.astro` renders the word "Malika" in
  Caveat. Replace it with an SVG scan of her handwriting, then drop Caveat from
  `scripts/font-manifest.mjs` and `--hand` from `src/styles/tokens.css`.
- **Byline avatar** — `src/components/Byline.astro` renders the letter M.
- **Open Graph card** — `public/og-default.png` (1200×630).

## TODO(social)

`SOCIAL.telegram` and `SOCIAL.instagram` in `src/lib/site.js` are **unset, not
placeholder values** — a guessed handle is an identity claim about whoever owns
that account. Until real handles land, the Telegram CTA, the footer social link
and the `/maxfiylik` contact line all hide themselves, and `sameAs` is omitted
from `Person` JSON-LD entirely rather than emitted empty. Set the two constants
and everything reappears; nothing else needs changing.

Alt text already describes the *intended* photograph, not the placeholder. When
you swap an image, re-read its `coverAlt` and make sure it still matches.
